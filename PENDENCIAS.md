# Pendências não essenciais

Esta lista existe para registrar somente itens **não essenciais** do projeto.

## Regra desta lista

Entram aqui apenas:
- etapas não essenciais;
- funções não essenciais;
- ajustes não essenciais.

Não entram aqui:
- correções críticas;
- bloqueios de funcionamento;
- itens necessários para o fluxo principal do MVP.

- [ ] Melhorar a experiência das listas com **busca, ordenação e paginação**.

## Observação

Quando uma etapa do checklist original for considerada **não essencial**, ela deve ser movida para esta lista em vez de entrar no fluxo principal de implementação.
